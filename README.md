# digilab.ai News Studio

Statischer Instagram-News-Composer fuer `digilab.ai` in DWD-naher CI.

## Features

- verschiebbares Logo
- Headline, Kicker, Meta- und Textbloecke
- variable, pixelige Hintergrundformen
- mehr Typografieoptionen statt Animation
- PNG-Export

## Lokaler Start

```bash
npm install
npm run dev
```

## Build

```bash
npm run build
```
